# Compresto CLI releases

Release downloads for `compresto`, the command-line version of
[Compresto](https://compresto.app). It compresses videos, images, GIFs and
PDFs on macOS.

## Install

```bash
brew install dqhieu/tap/compresto
```

Then sign in once with your Compresto license:

```bash
compresto auth login
```

Run `compresto --help` for usage. A Compresto license is required.

This repository only hosts the downloads. For help, see
[compresto.app](https://compresto.app).
